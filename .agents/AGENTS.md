# Git Commit Guidelines

- **Autorstwo commitów**: Wszystkie commity w tym repozytorium muszą być tworzone przy użyciu tożsamości użytkownika `Predi97` (email: `44264373+Predi97@users.noreply.github.com`).
- **Brak stopek AI**: Nigdy nie dodawaj stopek `Co-Authored-By` (np. przypisujących współautorstwo modelom AI, takim jak Claude, Gemini czy Antigravity) do wiadomości commitów. Wszystkie działania mają być przypisane wyłącznie użytkownikowi `Predi97`.
- **Przebieg prac przez Pull Request (PR)**: Wszystkie zmiany w kodzie i nowe funkcjonalności muszą być wdrażane poprzez proces Pull Request. Zmiany najpierw trafiają na dedykowaną gałąź (np. `feature/nazwa`), a następnie jest tworzony PR, który po scaleniu z gałęzią `master` zostaje zamknięty. Nigdy nie wprowadzaj zmian bezpośrednio na gałęzi `master`.
- **Język opisów**: Wszystkie tytuły commitów, opisy commitów oraz tytuły i opisy Pull Requestów (PR) muszą być tworzone w języku angielskim.
